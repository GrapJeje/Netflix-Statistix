- [x] Spring Boot-project aanmaken.
- [x] PostgreSQL database opzetten.
- [x] Databaseverbinding configureren.
- [ ] Basisstructuur van het project opzetten (packages).
- [x] Controleren of de applicatie verbinding kan maken met de database.

## 2. Database ontwerpen
- [x] Database modellen (entities) aanmaken.
- [x] Relaties tussen de modellen opzetten.
- [x] ERD maken.
- [ ] Testdata voorbereiden (films, series, afleveringen en accounts).

## 3. Authenticatie
- [ ] Inloggen met accountnaam.
- [ ] Ingelogde account opslaan tijdens de sessie.
- [ ] Uitloggen.
- [ ] Toegang tot gegevens beperken tot het ingelogde account.
- [ ] Nieuw account kunnen aanmaken.

## 4. Profielen beheren
- [ ] Overzicht van alle profielen binnen een account.
- [ ] Profiel aanmaken.
- [ ] Profiel bewerken.
- [ ] Profiel verwijderen.
- [ ] Profiel selecteren om de applicatie te gebruiken.
- [ ] Account + data kunnen verwijderen

## 5. Programmaoverzicht
- [ ] Overzichtspagina met alle films en series.
- [ ] Programma's kunnen filteren op genre.
- [ ] Onderscheid maken tussen films en series.
- [ ] Aanbevolen series weergeven op basis van bekeken series.

## 6. Programmadetails
- [ ] Detailpagina voor films.
- [ ] Detailpagina voor series.
- [ ] Informatie over afleveringen weergeven.
- [ ] Genre, taal, leeftijdsindicatie en tijdsduur weergeven.
- [ ] Overzicht van aanbevolen series tonen.

## 7. Kijkgeschiedenis
- [ ] Bekeken programma's toevoegen aan een profiel.
- [ ] Percentage bekeken kunnen opslaan.
- [ ] Percentage bekeken kunnen aanpassen.
- [ ] Bekeken programma's uit de kijkgeschiedenis verwijderen.
- [ ] Kijkgeschiedenis per profiel weergeven.

## 8. Reports (/reports)
- [ ] Gemiddeld bekeken percentage per aflevering van een geselecteerde serie.
- [ ] Gemiddeld bekeken percentage per aflevering binnen een geselecteerd account.
- [ ] Alle bekeken films van een geselecteerd account.
